MAAZ FARMS STORE

Open index.html. Every menu section opens on its own page.

Features: shop, fruits, vegetables, add to cart, cart quantity controls, totals, demo checkout, contact form, responsive navigation, dedicated owner/farm photo slots.

YOUR PHOTOS
Replace files in assets/photos/ with your own photos, or send your photos in ChatGPT and they can be inserted for you.

Real payments and live order processing require a payment gateway and backend.

SECURITY NOTE
This version is a front-end demo. Accounts, passwords, orders and payment choices use browser localStorage. Do NOT use this authentication/payment implementation for a real production store. For production, connect a secure backend database, password hashing/session authentication, and a real payment gateway such as Razorpay/Stripe/etc.
